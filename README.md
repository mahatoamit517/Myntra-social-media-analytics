# Myntra Social Media Analytics Project

## Objective
Analyze Myntra's social media performance across platforms.

## Tools Used
- Excel
- Power Query
- Pivot Tables
- Data Visualization

## Key Insights
- Reels & videos drive highest engagement
- Campaign hashtags outperform generic ones
- Instagram shows best engagement ROI
- Ad spend does not always guarantee higher engagement

## Strategic Recommendations
- Platform-specific content strategy
- Engagement-led ad optimization
- Campaign-aligned follower growth strategy
